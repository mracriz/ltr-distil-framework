# llm-as-judge-for-ltr

Repositorio para experimentos com LLM em ranking, analise e carregamento de dados.

## Setup rapido

1. Instale o Poetry.
2. Rode:

```bash
poetry install
poetry run python -m ipykernel install --user --name llm-as-judge-for-ltr
```

3. Para abrir notebook:

```bash
poetry run jupyter lab
```
